# Tasks

Every implementation task follows Red -> Green -> Refactor: write the named failing test(s) first, run them and confirm they fail for the expected reason, implement the minimum to pass, refactor (SRP, clear names), then run `uv run pytest` and `uv run ruff check`. Each numbered task is one atomic Conventional Commit (imperative, subject < 72 chars, no trailing period, no co-author or AI attribution lines). Default tests stay offline: fake model/chat engines, fake wording, fake confirmer, fake PIN prompt, fake stdio MCP server, injected clocks; no real model, no real stdin, no real display (`QT_QPA_PLATFORM=offscreen`). Real-model tests are marked `evals`.
