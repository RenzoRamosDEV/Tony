# Tasks

Every implementation task follows Red -> Green -> Refactor: write the named failing test(s) first, run them and confirm they fail for the expected reason, implement the minimum to pass, refactor (SRP, clear names, Boy Scout rule), then run the affected suite. Each numbered task is one atomic Conventional Commit (imperative, subject < 72 chars, no trailing period, no co-author or AI attribution lines). Python tests: fakes first (`tests/fakes/`), injected clocks, `QT_QPA_PLATFORM=offscreen`, explicit bounds on every wait (`qtbot.waitUntil(..., timeout=5000)`, `join(5)`), under the 30 s per-test timeout; the default suite never starts a Chromium renderer. Frontend tests: vitest + Testing Library on jsdom with a fake `TonyBridge` and fake scenes; no GPU, no network. Source of ported files: `git show main:tony/apps/web/frontend/<path>`.
