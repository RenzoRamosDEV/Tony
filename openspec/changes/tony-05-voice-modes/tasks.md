# Tasks

Convenciones: TDD obligatorio (RED → GREEN → REFACTOR) por módulo; cada grupo empieza con pruebas en rojo y termina con `uv run pytest <ficheros>` (backend) o `npm test -- <fichero>` (frontend) en verde. La suite estándar nunca usa motores reales, red ni modelo: `FakeVad`/`FakeStt`/`FakeTts` (`tests/fakes/voice.py`), WAV sintéticos de `tests/fixtures/audio/`, `FakeConversationRunner`, `TestClient` de FastAPI, `AudioContext`/`WebSocket` simulados en Vitest. Los motores reales solo bajo `uv run pytest -m voice`. Identificadores en inglés, textos de usuario en español. Ver design.md D1 (layout), D2–D7 (decisiones fijadas) y D10 (estrategia de pruebas). Antes de empezar: la entrega anterior (`tony web`) archivada y `main` limpio; `uv sync --extra web --group dev` ejecutado.
