# Tasks

Every implementation task follows Red -> Green -> Refactor: write the named failing test(s) first, run them and confirm they fail for the expected reason, implement the minimum to pass, refactor (SRP, clear names), then run `uv run pytest` and `uv run ruff check`. Each numbered task is one atomic Conventional Commit (imperative, subject < 72 chars, no trailing period, no co-author or AI attribution lines). Default tests stay offline and fast: fake model/chat engines, fake confirmer, fake stdio MCP server, fake audio (`tests/fakes/voice.py`), fake notifier and hotkeys, injected clocks, `QT_QPA_PLATFORM=offscreen`; no real model, audio device, D-Bus or X server. Real-engine tests are marked `voice` (excluded by default), real-model tests `evals`. Every test that waits on a thread, a Qt signal or an asyncio event uses an explicit bound (`asyncio.timeout(5)`, `qtbot.waitUntil(..., timeout=5000)`, `join(5)`) and stays under the 30 s per-test timeout.
