# Tasks

Convenciones: TDD obligatorio (RED → GREEN → REFACTOR) por módulo; cada grupo empieza con pruebas en rojo y termina con `uv run pytest <ficheros>` (backend) o `npm test -- <fichero>` (frontend) en verde. Ninguna prueba usa red ni modelo real: `FakeConversationRunner` (ampliado con `chunks`), `FakeWorkerFactory` + `ScriptedRunner`, `FakeClock`, `ListChannel`, `TestClient` de FastAPI (HTTP y `websocket_connect`), `fetch` y `WebSocket` simulados en Vitest. Identificadores en inglés, textos de usuario en español. Ver design.md D1 (layout), D5–D9 (decisiones fijadas) y D12 (estrategia de pruebas). Antes de empezar: la entrega anterior (skills, subagentes, hot reload, doctor) archivada y `main` limpio; `uv sync --extra web --group dev` ejecutado.
