# Tasks

Every implementation task follows Red -> Green -> Refactor: write the named failing test(s) first, run them and confirm they fail for the expected reason, implement the minimum to pass, refactor (SRP, clear names), then run `uv run pytest` and `uv run ruff check`. Each numbered task is one atomic Conventional Commit (imperative, subject < 72 chars, no trailing period, no co-author or AI attribution lines). Default tests stay offline and fast: fake model/chat engines, fake confirmer, fake stdio MCP server (`tests/fakes/fake_fs_server.py`), fake change streams instead of real file watching, injected clocks; no real model. Real-model tests are marked `evals` and only run with `TONY_EVALS=1`. Every test that touches asyncio or MCP stays within the 30 s per-test timeout; any test waiting on an event uses an explicit `asyncio.timeout(...)` bound.
